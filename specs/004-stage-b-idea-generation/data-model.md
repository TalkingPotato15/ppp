## Entities

### GenerationSession

A single idea generation session linking a user to a problem.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| id | UUID (String 36) | PK | Unique session identifier |
| user_id | UUID (String 36) | FK → users.id, NOT NULL | User who initiated generation |
| problem_id | UUID (String 36) | NOT NULL, INDEX | Problem from Stage A (references DocumentSummary) |
| status | Enum | NOT NULL, DEFAULT 'PENDING' | Generation status |
| feedback | Text | NULL | DEPRECATED - was for regeneration feedback |
| error_message | Text | NULL | Error details if generation failed |
| created_at | DateTime (TZ) | NOT NULL, DEFAULT NOW | Session creation timestamp |
| completed_at | DateTime (TZ) | NULL | Generation completion timestamp |

**Status Enum Values**:
- `PENDING` - Session created, generation not started
- `GENERATING` - AI agent processing in progress
- `COMPLETED` - Ideas generated successfully
- `FAILED` - Generation failed with error

**Indexes**:
- `ix_generation_sessions_user_id` on `user_id`
- `ix_generation_sessions_problem_id` on `problem_id`

**Business Rules**:
- Only ONE completed session allowed per (user_id, problem_id) combination
- Sessions in GENERATING status for >5 minutes should be marked FAILED (cleanup job)

### GeneratedIdea

An individual business idea generated by the AI agent.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| id | UUID (String 36) | PK | Unique idea identifier |
| session_id | UUID (String 36) | FK → generation_sessions.id, NOT NULL | Parent generation session |
| title | String (500) | NOT NULL | Idea title/name |
| description | Text | NOT NULL | Detailed description of the business idea |
| target_audience | Text | NOT NULL | Who this idea serves |
| differentiators | JSON (Array) | NOT NULL, DEFAULT [] | Key differentiators as list of strings |
| market_opportunity | Text | NOT NULL | Market analysis and opportunity description |
| implementation_hints | Text | NOT NULL | High-level implementation guidance |
| is_bookmarked | Boolean | NOT NULL, DEFAULT FALSE | Whether user has bookmarked this idea |
| created_at | DateTime (TZ) | NOT NULL, DEFAULT NOW | Idea creation timestamp |

**Indexes**:
- `ix_generated_ideas_session_id` on `session_id`

**Cascade Behavior**:
- DELETE session → DELETE all associated ideas

**Business Rules**:
- Ideas are immutable once created (no updates except `is_bookmarked`)
- 3-5 ideas created per session
- Ideas persist indefinitely (paid content)

### SavedIdea (DEPRECATED)

> **Note**: This entity is deprecated. Use `is_bookmarked` field on `GeneratedIdea` instead.
> Kept for backwards compatibility with existing data.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| id | UUID (String 36) | PK | Unique saved idea identifier |
| user_id | UUID (String 36) | FK → users.id, NOT NULL | User who saved the idea |
| idea_id | UUID (String 36) | FK → generated_ideas.id, NOT NULL | The saved idea |
| notes | Text | NULL | User notes about the idea |
| saved_at | DateTime (TZ) | NOT NULL, DEFAULT NOW | When the idea was saved |

**Migration Path**:
- Existing SavedIdea records can be migrated by setting `is_bookmarked = TRUE` on corresponding GeneratedIdea
- No new SavedIdea records should be created
- Endpoints using SavedIdea should be deprecated in favor of bookmark endpoints

## State Transitions

### GenerationSession Status

```
                    ┌─────────────────────────┐
                    │                         │
                    ▼                         │
┌─────────┐   ┌────────────┐   ┌───────────┐ │
│ PENDING │──▶│ GENERATING │──▶│ COMPLETED │ │
└─────────┘   └────────────┘   └───────────┘ │
                    │                         │
                    │         ┌────────┐      │
                    └────────▶│ FAILED │──────┘
                              └────────┘
                              (can retry*)

* Retry creates new session, not allowed per spec
  Shown for error recovery edge case only
```

**Transitions**:
- PENDING → GENERATING: When AI agent call starts
- GENERATING → COMPLETED: When ideas are successfully saved
- GENERATING → FAILED: When AI agent returns error or times out
- FAILED → (new session): Not allowed per spec (one-time generation)

## Validation Rules

### GenerationSession
- `user_id` must reference existing user
- `problem_id` must reference existing DocumentSummary
- Cannot create session if completed session exists for same (user_id, problem_id)

### GeneratedIdea
- `title` max length: 500 characters
- `differentiators` must be array of strings (3-10 items typical)
- All text fields must be non-empty

## Database Migration Required

```sql
-- Add is_bookmarked column to generated_ideas
ALTER TABLE generated_ideas
ADD COLUMN is_bookmarked BOOLEAN NOT NULL DEFAULT FALSE;

-- Create index for bookmark queries
CREATE INDEX ix_generated_ideas_is_bookmarked
ON generated_ideas(is_bookmarked)
WHERE is_bookmarked = TRUE;

-- Migrate existing saved_ideas to bookmarks
UPDATE generated_ideas
SET is_bookmarked = TRUE
WHERE id IN (SELECT idea_id FROM saved_ideas);
```

## Query Patterns

### Get user's bookmarked ideas
```sql
SELECT gi.*
FROM generated_ideas gi
JOIN generation_sessions gs ON gi.session_id = gs.id
WHERE gs.user_id = :user_id
  AND gi.is_bookmarked = TRUE
ORDER BY gi.created_at DESC;
```

### Check if user already generated ideas for problem
```sql
SELECT COUNT(*) > 0
FROM generation_sessions
WHERE user_id = :user_id
  AND problem_id = :problem_id
  AND status = 'COMPLETED';
```

### Get all ideas for a problem (with bookmark status)
```sql
SELECT gi.*, gi.is_bookmarked
FROM generated_ideas gi
JOIN generation_sessions gs ON gi.session_id = gs.id
WHERE gs.user_id = :user_id
  AND gs.problem_id = :problem_id
  AND gs.status = 'COMPLETED';
```
