## TC-001: 제약조건 입력 폼 - 예산 선택

### 시나리오
사용자가 기술 사양서 생성을 위해 예산 범위를 선택한다.

### 사전조건
- 아이디어 상세 페이지에서 "기술 사양서 생성" 버튼 클릭
- 제약조건 입력 폼이 표시됨

### 테스트 단계
| 단계 | 행동 | 예상 결과 |
|------|------|----------|
| 1 | 예산 범위 중 "1,000만원 미만" 선택 | 해당 버튼이 파란색으로 하이라이트됨 |
| 2 | "1,000만원 ~ 5,000만원"으로 변경 | 이전 선택 해제, 새 선택 하이라이트 |
| 3 | "구체적인 예산 금액 입력" 체크박스 클릭 | 금액 입력 필드가 나타남 |
| 4 | "30,000,000" 입력 | "30,000,000원" 형식으로 표시됨 |
| 5 | "다음" 버튼 클릭 | 팀 구성 단계로 이동 |

### 합격 기준
- [ ] 4개 예산 범위 옵션이 모두 표시됨
- [ ] 한 번에 하나만 선택 가능
- [ ] 구체적 금액 입력 시 천 단위 콤마 자동 포맷
- [ ] 예산 미선택 시 "다음" 버튼 클릭 시 에러 메시지 표시

## TC-002: 제약조건 입력 폼 - 팀 구성

### 시나리오
사용자가 팀 규모와 구성원 레벨을 입력한다.

### 사전조건
- TC-001 완료 후 팀 구성 단계

### 테스트 단계
| 단계 | 행동 | 예상 결과 |
|------|------|----------|
| 1 | 팀 규모 슬라이더를 5로 조정 | "5명" 표시 |
| 2 | 주니어 + 버튼 2회 클릭 | 주니어: 2명 |
| 3 | 미들 + 버튼 2회 클릭 | 미들: 2명 |
| 4 | 시니어 + 버튼 1회 클릭 | 시니어: 1명 |
| 5 | 합계 확인 | "2 + 2 + 1 = 5" 팀 규모와 일치 |
| 6 | "다음" 버튼 클릭 | 일정 단계로 이동 |

### 합격 기준
- [ ] 팀 규모 1~20명 범위 선택 가능
- [ ] 구성원 합계가 팀 규모와 불일치 시 에러 표시
- [ ] 음수 입력 불가 (- 버튼 0에서 비활성화)

- [ ] 클릭으로 버전 전환 가능
